Guía de Configuración y Conexión a Firebase Firestore

Arquitectura Cloud Firestore:

El sistema consulta la colección obligatoria Usuarios en la ruta pública de artefactos de Firestore. Para registrar automáticamente las credenciales institucionales, presione el botón verde en la pantalla de inicio.

1

Crear proyecto en Firebase Console

Ingrese a Firebase Console, cree un proyecto y active Cloud Firestore en modo de prueba.

2

Colección "Usuarios" (Credenciales y Roles)

Campos requeridos en Firestore:

  • usuario (string): admin, validador, tula, etc.
  • password (string): Contraseña de acceso
  • tipoAcceso (string): Administrador, Validadores o Distritos
  • distritoAsignado (string, opcional): Ej. Distrito Tula
3

Colección "RegistroDatos"

Las planeaciones semanales se sincronizan de forma segura en RegistroDatos.
